# Mini-Todo 桌面应用 - 项目概述

## 1. 项目简介

Mini-Todo 是一款 Windows 桌面待办事项管理应用，PC 端基于 Rust + GPUI 开发（`pc-gpui/`），单个 `mini-todo.exe`、不依赖 WebView2，
具有独特的窗口固定 / 嵌入桌面功能、桌面收纳箱和现代化的用户界面。

> 1.x ~ 2.x 的 PC 端基于 Tauri 2 + Vue 3（原 `pc/` 目录），3.0 起由 GPUI 重写版取代并删除（见 git 历史）；两者数据完全兼容。

## 2. 项目目标

- 提供简洁高效的待办事项管理体验
- 支持系统级通知提醒与重复提醒
- 实现窗口固定功能（固定位置、不占任务栏；可选嵌入桌面，Win+D 不隐藏）
- 采用现代化 UI 设计
- 支持数据导入导出与 WebDAV 云同步，方便迁移与多设备使用

## 3. 技术栈

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| UI 框架 | GPUI（gpui-kit 0.7.3） | Zed 编辑器的 GPU 加速 UI 框架，Windows 上 DirectX 11 + DirectComposition |
| 控件 | 自绘 Element Plus 风格控件 | `pc-gpui/crates/app/src/ui/` |
| 业务核心 | Rust（`mini-todo-core`） | `pc-gpui/crates/core`，阻塞函数，不依赖 GUI 框架 |
| 数据库 | SQLite（rusqlite） | 轻量级本地数据库 |
| 系统通知 | notify-rust | Windows Toast |
| 平台集成 | windows crate、tray-icon、auto-launch | Win32 窗口能力、托盘、开机自启 |

## 4. 核心功能

### 4.1 待办管理
- 创建、编辑、删除待办事项
- 支持一级子任务
- 优先级设置（高/中/低）与四象限
- 完成状态标记
- 拖拽排序

### 4.2 通知提醒
- Windows 系统通知 / 应用内通知
- 预设提醒时间（5/15/30 分钟）
- 自定义提前时间
- 重复提醒（按天 / 周 / 周几 / 月几号）

### 4.3 窗口特殊功能
- **普通模式**：可拖拽移动、调整大小
- **固定模式**：
  - 固定在用户指定位置，禁止拖动与缩放
  - 不在任务栏、不参与 Alt+Tab
  - 可选嵌入桌面：位于桌面图标之上、所有应用窗口之下，Win+D 不隐藏（Win11 24H2+）

### 4.4 数据管理
- SQLite 本地存储（`%LOCALAPPDATA%\mini-todo\`）
- ZIP / JSON 格式导入/导出
- 数据库迁移（升级前自动备份）
- WebDAV 云同步（逐条合并）

## 5. 目标平台

- **主要支持**：Windows 10/11 x64
- **测试环境**：Windows 11（CI 另在 Linux 上跑截图回归与端到端测试）

## 6. 项目结构

> 项目按平台拆分子目录，`pc-gpui/` 为 Windows 桌面端（GPUI），`cloud/` 为云端 HTTP API。

```
mini-todo/
├── docs/                        # 共享文档目录
│   └── 开发文档/                 # 开发相关文档
├── pc-gpui/                     # PC 端（Cargo workspace）
│   ├── crates/
│   │   ├── core/                # 业务核心：db/、services/、todo / data / sync / settings / reminder / fence …
│   │   └── app/                 # GPUI 界面：windows/、ui/、services/、platform/、theme.rs、state.rs
│   ├── scripts/                 # 截图回归、端到端测试、Windows 安装器脚本
│   ├── Cargo.toml               # 工作区与版本号
│   └── Cargo.lock
├── cloud/                       # 云端 HTTP API（独立 crate）
└── CLAUDE.md / README.md        # 仓库说明
```
