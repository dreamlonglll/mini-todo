# Mini-Todo - UI 设计规范

> 本文是最初的视觉设计稿，用 SCSS 记法描述颜色、尺寸与交互意图，写于 Tauri + Vue 版时期。3.0 起 PC 端是 GPUI 版：
> 实际数值的唯一来源是 `pc-gpui/crates/app/src/theme.rs`（按窗口分节的颜色 / 字体 / 圆角 / 间距 / 阴影 token），
> 逐窗口的详细规格在 `.trellis/tasks/archive/2026-10/10-15-gpui-rewrite/research/ui-*.md`。下文的 CSS 选择器、`body.fixed-mode`
> 等只是设计意图的记法，不对应现有代码。

## 1. 设计理念

- **简洁现代**：采用扁平化设计，减少视觉噪音，**去除卡片边框**
- **高效交互**：快速添加、一键完成，减少操作步骤
- **视觉层次**：通过颜色圆点区分优先级和状态
- **透明美学**：固定模式下的毛玻璃透明效果
- **极简列表**：列表项无边框，使用圆点标识优先级

## 1.1 UI 组件库

- **组件库**：自绘的 Element Plus 风格控件（`pc-gpui/crates/app/src/ui/`，外观数值照抄 Element Plus，每种控件只有一个实现）
- **图标库**：Element Plus Icons（SVG 放在 `pc-gpui/crates/app/assets/icons/ep/`，经 `assets.rs` 的 `EpIcon` 使用）
- **禁止使用 emoji 图标**

## 9. 固定模式样式

固定模式下实现100%透明背景，只显示文字和图标：

```scss
// 固定模式下覆盖CSS变量实现透明
body.fixed-mode {
  --bg-primary: transparent;
  --bg-secondary: transparent;
  --bg-tertiary: rgba(255, 255, 255, 0.1);
  --shadow-sm: none;
  --shadow-base: none;
  --shadow-md: none;
  --shadow-lg: none;
  background: transparent !important;
}

// 所有容器元素透明
body.fixed-mode #app,
body.fixed-mode #app .app-container,
body.fixed-mode #app .app-container .title-bar,
body.fixed-mode #app .app-container .main-content,
body.fixed-mode #app .app-container .quick-add,
body.fixed-mode #app .app-container .todo-list,
body.fixed-mode #app .app-container .todo-item {
  background: transparent !important;
  background-color: transparent !important;
}

// 标题栏在固定模式下隐藏关闭和最小化按钮
body.fixed-mode .title-bar {
  .btn-close,
  .btn-minimize {
    display: none;
  }
}
```

### 9.1 实现要点（GPUI 版）

1. **透明窗口**：主窗口建窗时 `transparent = true`（Windows 上 DirectComposition），界面自己画圆角底色
2. **半透明外观**：上面的透明设计在 GPUI 版落在主窗口的深色主题调色板 `theme::Palette::dark`：底色 = 设置里的「界面底色」+「背景透明度」，
   阴影为 none、浅色文字；浅色主题为白底（`theme::light()`）
3. **固定模式**：经典固定时主窗口去掉圆角与描边；固定本身不改变配色
4. **切换**：配色由 `AppState.is_dark_theme` 决定，窗口通过 `cx.observe` 即时重绘

## 11. 图标规范（Element Plus Icons）

- 使用 Element Plus Icons（代码里是 `EpIcon::*`，下表的组件名去掉尖括号即变体名；表里的 `PriceTag` 目前未收录，用到时把 SVG 加进 `assets/icons/ep/` 并在 `assets.rs` 登记）

- **禁止使用 emoji 图标**

### 使用示例
