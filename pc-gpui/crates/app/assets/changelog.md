## 未发布

- 新增「更新日志」：升级后第一次打开时显示新版本的变化，也可以在设置 → 关于里随时查看
- 新建待办更快：在清单窗口里按 Ctrl+N（macOS：⌘N），或双击列表的空白处；在四象限里双击某个象限的空白处，新待办直接放进这个象限
- 清单窗口锁定后不再显示右下角的新建按钮，界面更简洁
- 在日历窗口里双击某一天新建待办，开始时间预填为那一天；清单筛选只选了一个清单时，新待办建到那个清单

## 3.1.0-pre（2026-11-10）

### 多个待办清单

- 托盘（macOS：菜单栏图标）右键「新增待办清单」，每个清单是一个独立的桌面窗口，可以按"工作 / 生活"等分类放待办
- 双击标题栏上的清单名改名；右键清单名可以删除清单，其中的待办移到「待办清单」（原来的主窗口，不能删除）
- 编辑待办时用「清单」下拉，或在列表里右键待办「移动到」，把它移到别的清单
- 每个清单窗口有自己的列表 / 四象限、日 / 夜和锁定，「已完成」只看本清单
- 清单随 WebDAV 同步；窗口的位置、锁定和外观是每台电脑自己的

### 日历是单独的窗口

- 在设置 → 常规「展示日历」或托盘「显示日历」打开，显示所有清单的待办；标题栏的漏斗按钮可以只看某几个清单

### 窗口的变化

- 锁定按窗口：每个清单 / 日历窗口标题栏都有锁形按钮，托盘里不再有「固定模式」
- 拖动、缩放窗口时会与其它窗口和收纳箱的边对齐（按住 Alt，macOS 按住 Option 临时不对齐）；不再支持 Windows 的贴靠布局和双击标题栏最大化
- 关闭清单 / 日历窗口只是隐藏，点托盘图标全部唤回；退出请用托盘菜单「退出」
- 托盘「重置位置」把所有清单窗口和日历窗口重新排好并解除锁定

### 其它

- 粘贴或拖入的大图默认按 240 宽显示，拖图片的手柄可以放大
- 修复：列表较长时，点右下角的新建按钮会误点到下面那行的「删除」
